# Navichrome 0.1.0-beta.4

This release adds the first complete playlist-management, queue-management, and Start Radio workflow on top of the existing Navidrome player.

## What's changed

- Added native Navidrome playlist management: create, rename, delete, add, remove, and reorder tracks.
- Added Save Queue as Playlist and playlist creation from track and album actions.
- Added queue drag reordering, Jump to Current, safer queue clearing, and improved context-menu actions.
- Added playlist sorting with a custom order and an animated drag-and-drop experience on touch devices.
- Added Start Radio from tracks, albums, playlists, and artists through the shared player queue.
- Fixed queue advancement with repeat-one enabled and kept radio recommendations out of the way of the mobile player.
- Synced queue Starred actions with Navidrome so queue hearts match the Starred page.
- Improved mobile queue controls and playlist creation spacing.
