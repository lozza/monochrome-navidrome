# Navichrome 0.1.0-beta.5

This release hardens the beta.4 playlist, queue, and Start Radio features and brings the project documentation and dependency lockfile back in sync.

## What's changed

- Synced the tested Phase 3 player, queue, radio, and mobile improvements into the release branch.
- Added browser coverage for native playlist creation, adding the current track, playlist drag reordering, and queue drag reordering.
- Improved the browser Navidrome fixture so playlist mutations are verified end to end.
- Aligned `package-lock.json` with the application version used by Docker and CI.
- Updated the README to describe native playlist management and the current beta image.
