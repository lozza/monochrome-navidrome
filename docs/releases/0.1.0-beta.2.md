# Navichrome 0.1.0-beta.2

Small beta update, mainly fixing a couple of things I noticed while using it.

## What's changed

- Fixed duplicate tracks showing up in search results when there is only one copy of the album in Navidrome.
- Tidied the checks on GitHub so lint and Lighthouse are behaving properly again.
- Docker now publishes the matching version tag as well as `latest`, so it is easier to pin a build if you do not want it changing underneath you.

There are no big UI changes in this one. It is mostly a bug-fix release and a cleaner base for the next round of testing.

It is still beta at the min, so if you find anything odd, please stick it in GitHub Issues with what device/browser you are using and what you were doing when it happened.

## Docker

Latest:

`ghcr.io/lozza/monochrome-navidrome:latest`

Pinned to this release:

`ghcr.io/lozza/monochrome-navidrome:0.1.0-beta.2`

If you are already using `latest`, just pull the image again and redeploy your existing container/stack.
