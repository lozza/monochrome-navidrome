This is the first controlled beta of Navichrome, the self-hosted Navidrome/OpenSubsonic web player.

What is included:

- Navidrome/OpenSubsonic login, library browsing, search, and playback
- Server-backed starred tracks, playlists, scrobbling, and recent history
- Smoother Singles browsing for large libraries, including instant 0–Z navigation and bounded rendering
- Artwork fallback, lyrics, and music downloads
- PWA installation and cache updates
- Removal of the old Monochrome services, authentication systems, telemetry, and promotional pages
- CI checks for formatting, lint, tests, builds, and Docker metadata

Docker:

`ghcr.io/lozza/monochrome-navidrome:0.1.0-beta.1`

Existing installations may continue using:

`ghcr.io/lozza/monochrome-navidrome:latest`

Portainer users should re-pull the image and redeploy the existing stack. The container name, ports, `/navidrome` server URL, host-gateway entry, and health check remain unchanged.

Each device must sign in separately. Navidrome-backed listening history follows the account, but queues and settings do not fully sync. Playlist viewing is supported; playlist editing is not claimed.

This is beta software. When reporting a problem, include the Navichrome version and build commit, browser/device details,
Navidrome version, deployment method, and steps to reproduce it.
