# Navichrome 0.1.0-beta.3

Quick fix for the duplicate tracks showing in search.

It turned out Navidrome itself can sometimes return the same song more than once with different internal IDs. Navichrome now checks the track details as well, so those duplicates are hidden before the results are shown.

## What's changed

- Fixed duplicate tracks in search even when Navidrome gives the same song different IDs.
- Added checks for matching file path and track details so the same song only shows once.
- Added tests for this exact case.
