This is a retrospective release for the early Navichrome preview that was previously served by `latest`.

It points to commit `94e47e6b855ba8f9298fe2c2a00cae21104b13e7` from 29 August 2026. That snapshot still carried the inherited application version `2.5.1`; `0.1.0-alpha.1` is a retrospective release label so the pre-beta state remains easy to find.

Docker image:

`ghcr.io/lozza/monochrome-navidrome:sha-94e47e6`

This image is retained for comparison and rollback. New installations should use `0.1.0-beta.1` or `latest`.

The alpha predates the beta security cleanup, expanded tests, and large-library Singles improvements.
