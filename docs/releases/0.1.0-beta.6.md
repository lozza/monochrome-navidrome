# Navichrome 0.1.0-beta.6

This release is a small accessibility fix: modal close buttons that showed only the "×" character had no accessible
name, so screen readers announced them as blank or read the raw character.

## What's changed

- Added `aria-label="Close"` to the icon-only close buttons across the app (artist biography, add-to-playlist,
  keyboard shortcuts, customize shortcuts, missing tracks, and discography download modals).
- Updated the README's current-beta references from `0.1.0-beta.4` to `0.1.0-beta.6`.
